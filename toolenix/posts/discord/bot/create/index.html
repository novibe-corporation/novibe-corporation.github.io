Créer un bot Discord

Ce guide vous aide à créer un bot Discord en Python étape par étape.

1. Installer Python

Téléchargez Python depuis python.org puis installez-le.

2. Installer discord.py

pip install discord.py

3. Créer le fichier du bot

import discord

client = discord.Client()

@client.event
async def on_ready():
    print("Bot connecté")

@client.event
async def on_message(message):
    if message.content == "!ping":
        await message.channel.send("Pong !")

client.run("TON_TOKEN_ICI")

4. Ajouter le bot à votre serveur

Dans le portail développeur Discord, créez une application, activez le bot et copiez le lien d’invitation.

5. Lancer le bot

python bot.py

Votre bot est maintenant en ligne.
